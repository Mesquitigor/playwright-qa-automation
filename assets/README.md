# First Light - Réplicas em Alta Qualidade

Réplicas vetoriais do logo "First Light" criadas em formato SVG para **tamanho e qualidade superiores** às imagens originais.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `first-light-logo.svg` | Versão com paleta **rose gold** – tons dourados-rosados, folhas em sage green, flores em blush pink |
| `first-light-logo-desaturated.svg` | Versão **desaturada** – tons oliva/bege, estética vintage e suave |

## Características

- **Formato vetorial (SVG)**: escala infinita sem perda de qualidade
- **Dimensões**: 2400 × 3000 px (3× maior que o original 800×1000)
- **Elementos**: texto "First Light", lua crescente, grinalda floral, estrelas e elementos celestes
- **Fundo preto** conforme o design original

## Como usar

### Visualização
- Abra os arquivos `.svg` diretamente no navegador ou em editores como Inkscape/Illustrator
- Use `export-viewer.html` para alternar entre versões e tamanhos

### Exportar para PNG em alta resolução
1. Abra `export-viewer.html` no navegador
2. Selecione a imagem e o tamanho (até 3200×4000 px)
3. Clique em "Exportar como PNG" ou use a captura de tela do sistema

### Ferramentas externas (maior controle)
- **Inkscape** (gratuito): `File → Export PNG Image` – defina o DPI para qualidade de impressão
- **GIMP**: importe o SVG e exporte no tamanho desejado
- **Adobe Illustrator**: exporte em qualquer resolução
